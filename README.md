# Veiklu Pasaulis

Create a modern, clean, and user-friendly directory website in Lithuanian language for finding extracurricular activities and clubs ("būreliai") for children and adults across Lithuania, starting with Vilnius. Use a brand name "Veiklų Pasaulis".

Core features to build:

1. Header: Logo, navigation links ("Visi būreliai", "Įdėti būrelį"), and "Prisijungti / Registruotis" buttons.

2. Hero Section: Welcoming Lithuanian headline (e.g., "Rask geriausius būrelius vaikams ir suaugusiems"), a search bar, and a prominent filter bar with:

   - Miestas (Vilnius, Kaunas, Klaipėda, Šiauliai, Panevėžys, Visi miestai)

   - Mikrorajonas (Visi, Antakalnis, Žvėrynas, Centras, Pašilaičiai, Šeškinė, Pilaitė, Fabijoniškės, Naujamiestis)

   - Auditorija (Visi, Vaikams, Suaugusiems)

   - Amžiaus grupė (Visi, 3-5 m., 6-9 m., 10-13 m., 14-18 m., Suaugusiems)

   - Lytis (Visi, Berniukams, Mergaitėms)

   - Kategorija (Visos, Šokiai, Sportas, Menai, IT ir robotika, Muzika, Kalbos)

3. Activity Listings Grid: Display 8 realistic sample listings in Vilnius (in Lithuanian) with photos, title, category badge, location/district, age group, gender tag, and monthly price. Make all filters work dynamically on these listings.

4. Activity Detail View: Clicking any listing opens a full page/modal with detailed description, schedule, address, price, and a contact/inquiry form ("Susisiekti su būrelio vadovu").

5. Add Listing Flow ("Įdėti būrelį"): A clean form allowing club owners to submit a new activity (title, city, district, category, audience, age, gender, price, description, contact info) which adds it to the list.

Design style: Clean, trustworthy, modern marketplace (similar to Airbnb or modern directory platforms), mobile-responsive, using crisp white backgrounds, soft slate gray borders, and vibrant blue/teal accent buttons.
